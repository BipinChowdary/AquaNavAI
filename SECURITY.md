# Security and disclosure

AquaNavAI is a research demonstration and is not an operational navigation
system. Do not use its routes for vessel control, collision avoidance, or
safety-of-life decisions.

The repository remains private while potentially patentable work is reviewed.
Do not add credentials, raw restricted data, precise private field-test
locations, or unpublished invention details to public web artifacts.

Report suspected security issues privately to the repository owner. Do not
open a public issue containing exploit details or secrets.
