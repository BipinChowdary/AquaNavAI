# Baseline v1 status

The deterministic proxy fixture contains 30 paired cases and exists to validate
the software, experiment, and web-export workflow. In the current fixture,
environmental A* has lower mean modelled energy than the distance baseline, but
that outcome is **not a scientific result** because the currents and bathymetry
are analytic proxies.

The proxy remains only as a regression fixture. The separate checksummed
`south-florida-noaa-v1` Navigation V2 release now contains 30 four-objective
cases (120 routes) derived from pinned CUDEM, RTOFS, and NDBC inputs. Neither
release is an operational navigation product.
