# Disclosure register

Repository status: **private**. License status: **withheld pending IP review**.

Record every external demonstration, repository access grant, abstract, poster,
paper draft, preprint, presentation, public deployment, and code/data release
before it occurs. Each entry must include date, audience, disclosed material,
public/private status, and reviewer approval.

The current public-build boundary permits only the frontend and bounded proxy or
reviewed scenario outputs. Raw inputs, engine code, notebooks, unpublished
method details, and patent-oriented claims remain private.
