# Repository working agreement

- Preserve `public/scenarios/south-florida-v1` as the deterministic proxy fixture.
- Never relabel proxy/modelled quantities as observations or measured vessel performance.
- NOAA network access belongs only in explicit acquisition/build commands; the browser is same-origin and offline-capable.
- Keep raw NOAA downloads under ignored `data/raw/` and commit only bounded processed artifacts.
- A production scenario change requires source and artifact checksum updates, schema validation, Python/TypeScript routing checks, and browser verification.
- Do not add a public license, publish engine methods, or deploy externally without an explicit IP/disclosure decision.
- Required language: “modelled energy” or “energy proxy”; “research demonstration only; not for navigation.”
